Study & Assignment Tracker

Product Overview
Study & Assignment Tracker is a local-first personal web app for students who want one place to manage schoolwork, revision, deadlines, exam preparation, and study habits. It is designed to help a student stay organized, track daily tasks, review completed work, and plan ahead without needing a login or cloud account. The app runs locally, stores data in SQLite through Prisma, and is intended for private personal use.

Core Purpose
The app helps the user:
- organize weekly classes and recurring study blocks
- automatically generate daily tasks from a weekly timetable
- track homework and revision by day
- mark tasks as complete and review progress
- view calendar-based workload and history
- manage recurring schedule templates without editing code
- support broader study habits with additional academic tools

Primary Workflow
1. The user defines recurring schedule templates for subjects, times, deadlines, and task type.
2. The app automatically generates daily task instances from those templates.
3. The dashboard shows what needs to be done today, what is coming tomorrow, and how much has been completed.
4. The user can open the calendar to inspect any date and its tasks.
5. The user can manually add one-off tasks or adjust recurring templates.
6. Completed work is stored in history for later review.

Main Features

1. Dashboard
- Clean home screen and command center
- Displays the current date and time
- Shows an inspirational quote at the top
- Presents today's schedule in time order
- Distinguishes task types visually:
  - HOMEWORK: solid primary border
  - REVISION: dashed secondary/orange border
- Includes one-click task completion controls
- Shows daily progress through a progress bar or progress widget
- Highlights tomorrow's tasks so the user can prepare in advance
- Designed for focus, clarity, and fast daily use

2. Full Calendar View
- Month or week style calendar grid
- Displays all scheduled assignments and revision blocks
- Uses color indicators to show which days contain homework or revision
- Allows clicking a day to open a modal with that day's tasks
- Shows subjects, times, and deadline information for the selected date
- Helps the user visualize workload across the month

3. Manual Input and Schedule Management
- Add one-off tasks manually
- Create new recurring schedule templates
- Edit existing templates
- Delete templates
- Manage the weekly timetable without touching code
- Useful when a semester schedule changes or new classes are added

4. History Page
- Shows all completed tasks
- Filters completed work by time range, such as:
  - last 7 days
  - last 30 days
  - all time
- Helps the user review what has already been finished
- Acts as a record of effort and consistency

5. Local Automation
- Every time the dashboard loads, the app checks the current day of week
- It looks up matching schedule templates
- It generates task instances for the current calendar date if they do not already exist
- This keeps the daily task list accurate and ready automatically
- Prevents duplicated tasks through existence checks

Task Types
The app supports two task categories:
- HOMEWORK
- REVISION

These are used throughout the dashboard, calendar, history, and schedule management views so the user can immediately recognize the purpose of each task.

Weekly Schedule Engine
The recurring schedule is stored as templates and turned into daily tasks automatically. Each template contains:
- day of week
- subject
- start time
- end time
- deadline day
- task type

This structure allows the app to behave like a recurring timetable engine rather than a static to-do list.

Database Model
The local database uses SQLite with Prisma ORM.

Main models:
- ScheduleTemplate
  - stores weekly recurring timetable items
- Task
  - stores daily task instances generated from templates or created manually

Behavior:
- templates are the source of truth for recurring study blocks
- tasks are the actual dated items the user completes
- completed tasks remain visible in history
